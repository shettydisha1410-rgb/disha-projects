# Air Quality Index Prediction Using Machine Learning

A machine learning and data-analysis project for studying AQI patterns using pollutant and weather-related parameters. The project includes data cleaning, exploratory analysis, model comparison, feature importance, spatial analysis, Delhi-specific trends, and weather-based AQI prediction.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Models
- Linear Support Vector Regression (LinearSVR)
- Decision Tree Regression
- Random Forest Regression

## Workflow
1. Clean and preprocess the AQI dataset.
2. Perform exploratory data analysis and visualization.
3. Train and compare regression models.
4. Evaluate models using MAE, MSE, RMSE and R².
5. Analyze feature importance and AQI trends.
6. Perform spatial, seasonal, weather and population-exposure analysis.

## Dataset
The raw CSV datasets are intentionally not stored in this repository because of their large size. Place the required dataset files in the project folder before running the scripts.
