# Auto Quiz Generator

A Django-based web application that generates multiple-choice quizzes from user-provided text and calculates the user's score.

## Features
- Accepts paragraph/text input
- Generates up to five questions from definition-style sentences
- Provides multiple-choice options
- Calculates the final score

## Technologies
- Python
- Django
- HTML/CSS
- SQLite (local development)

## Run locally
```bash
pip install django
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
